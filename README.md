# 😊 AI-Based Real-Time Emotion Detection System

An AI-powered real-time emotion detection system developed using Python, OpenCV, DeepFace, and TensorFlow. The system detects facial emotions from a live webcam, displays confidence levels, saves emotion logs, captures screenshots, generates reports, and provides visual analytics.

---

## 📌 Features

- 🎥 Real-time webcam emotion detection
- 😀 Detects emotions:
  - Happy
  - Sad
  - Angry
  - Fear
  - Surprise
  - Neutral
  - Disgust
- 📊 Emotion confidence percentage
- 📝 Emotion logging to CSV
- 📷 Automatic screenshot capture
- 📄 PDF report generation
- 📈 Dashboard with emotion statistics
- 🔐 Simple login interface
- 🕒 Live date and time display

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/RakshanajyothiBonda/Real-Time-Emotion-Detection-System.git
```

Move into the project

```bash
cd Real-Time-Emotion-Detection-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python deepface_emotion.py
```
